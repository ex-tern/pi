Build a quantum circuit on wires, then inspect what it does: probabilities, state vector, Bloch spheres, density matrix and entanglement.

Qubits 2

Pick a gate, then click a spot on a wire. Click a placed gate to remove it.

QuVI is a LabVIEW toolkit for composing and simulating quantum circuits by Murtaza Vefadar (Department of Physics, Gebze Technical University), described in “From Block Diagrams to Bloch Spheres: Graphical Quantum Circuit Simulation in LabVIEW”. The original runs in LabVIEW and is available from GitHub and VIPM.

This page is an independent browser implementation of the same model, made for Pi Tech Lab. It is not the original software. QuVI is © 2026 Murtaza Vefadar, released under the MIT licence.
