📊 Framework Architecture

Pi-Index filters noise and yields quantitative results strictly aligned with Responsible Research Assessment (RRA) and CoARA (Coalition for Advancing Research Assessment) guidelines.

System Pipeline

  1. Unified Multi-Source Intake & ZK-Identity Registry — ORCID iD / W3C DID verification, local PDF / Unpaywall DOI / OpenAlex ingestion, ZK double-blind assignment.
  2. Core Evaluation & Adversarial Analysis Pipeline (CoARA/RRA) — PyMuPDF layout extraction, deterministic MDAR/RRID scoring, multi-LLM consensus (Llama, Mistral, Qwen, Gemini, Scilem), adversarial logic integrity matrix.
  3. Blockchain Consensus, Cryptographic Proofs & Slashing Tokenomics — Proof-of-Research validation, anti-laundering slashing guard, soulbound piQ token minting.
  4. User Interface, Cartography & Institutional Policy Support — CoARA/DORA dossiers, AI defense rebuttal strategy, global map of science, Pidyne LSTM forecasting.

CoARA Compliance & Core Pillars

  • Diverse Research Outputs (C5 & C8): structurally evaluates open datasets, code repositories, and containerized executable environments.
  • Qualitative & Quantitative Balance (C1-C8): algorithms act as auditors, not replacements for peer review.
  • Transparency & Researcher Sovereignty: evaluation weights, logic states, and criteria scores are hashed and stored on Ethereum (Sepolia). Researchers retain sovereign ownership via DID/ORCID.
