What is this?

HAL-OS is a bootable x86 image with no operating system, compiler, assembler, display driver or font. Python emits the machine code; the CPU runs it from sector 0, and a two-layer ternary network of 32,000 neurons paints VGA mode 13h directly. Every byte sent down the serial port becomes training data.

Here the real boot image — built from the HAL-OS repository when this site was deployed — runs on v86, an x86 emulator in WebAssembly, entirely inside your browser. Nothing you inject leaves your machine. The weight disk is kept in this browser so the network remembers what it learned between visits; download it to keep it anywhere else.
