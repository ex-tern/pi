# `groq` SDK) — dropped to keep installs faster and the dependency surface
# smaller. Everything below is a real import.

# --- Scoring engine ---

numpy~=1.26

# --- Optional: PyTorch and Transformers are NOT installed by default ---
#
# They were in this list, so every deploy downloaded and shipped roughly 700MB
# of dependencies that the running application never imported. Both features
# that use them are off by default:
#
#   torch                  -> only the LSTM forecast (USE_LSTM_FORECAST=false).
#                             The default forecast is Holt's method in NumPy.
#   transformers/accelerate-> only the local TinyLlama chat model
#                             (ENABLE_SCILEM_LOCAL_MODEL=false). The assistant
#                             answers from live state and its knowledge base.
#
# Both imports are lazy and both paths degrade cleanly when the package is
# absent, so omitting them changes nothing about default behaviour — it only
# removes the build time, the image size and the memory pressure. That matters
# most on a small host, which is exactly where the unused weight hurt.
#
# To enable either, uncomment its block AND set the matching env var.
#
# LSTM forecast:
#   --extra-index-url https://download.pytorch.org/whl/cpu
#   torch~=2.4
#
# Local chat model (needs several GB of RAM — not viable on a small instance):
#   transformers~=4.45
#   accelerate~=0.34

openai~=1.51
